# CompLab

Comparable-company valuation multiples — enterprise value, EV/EBITDA, EV/EBIT,
P/E, P/B — computed by tested code from a small set of hand-verified SEC filings.

Built as a learning project for understanding how equity comps actually work,
including where the numbers physically come from and what happens at the edges
(negative EBITDA, missing data, dual share classes, companies that stop filing).

## What this is not

- Not investment advice, and never will produce a buy/sell/hold output.
- Not connected to a live data feed. It covers four companies
  (CROX, DECK, SKX, NKE) whose financials were transcribed by hand from their
  actual 10-K filings, not generated by AI. See `docs/SEED_DATA_GUIDE.md` for the
  transcription process and `data/demo/` for the source JSON.

## Running it locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Search by ticker or company
name (e.g. "nike") to land on a company page, or jump directly to
`/company/NKE`, `/company/CROX`, `/company/DECK`, or `/company/SKX`.

## Other useful commands

```bash
npm test        # Vitest — the finance calculation library's test suite
npm run multiples   # prints every computed multiple for all four companies
npm run build    # production build
```

## How it's organized

- `lib/finance/` — pure calculation functions (market cap, EV, multiples, margins).
  No I/O, no network calls, fully tested. This is the part of the codebase every
  number on the site traces back to.
- `data/demo/` — the hand-verified seed data, one JSON file per company, each
  figure tagged with its source, filing date, and retrieval date.
- `app/company/[ticker]/` — the company page.
- `docs/` — the planning and process documents this project was built against,
  including `ARCHITECTURE.md`, `MVP_SCOPE.md`, and the day-by-day build plans.

## Disclaimer

This is a demo product covering a small, hand-verified set of companies. Every
figure on a company page is labelled with its source, period, currency, and
retrieval date. Nothing in this project is investment advice.
